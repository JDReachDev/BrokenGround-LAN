# Changelog

## 1.4
- Dedicated server: double click "Start Dedicated Server.bat" to run a server without playing, in a console window
  (live log, commands: help, list, kick, ip, stop).
- Players connecting over the internet (router port forwarding) now reach the game server: the server answers with the
  address the player typed instead of the host's private LAN address.
- If a dedicated server is already running on your PC, choosing HOST in the game simply plays on it.
- LAN panel: the options are now HOST and JOIN, with a SERVER IP field (works for friends and dedicated servers).

## 1.3
- New look for the LAN panel on the login screen, matching the game's style (game font and colors).

## 1.2
- First public release.
